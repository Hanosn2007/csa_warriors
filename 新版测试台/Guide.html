Java Warrior Arena 使用指南

你要完成什么

你要为一个自动战斗战士写策略。地图、回合系统、图形界面和评分统计已经准备好，你只需要关注一个核心问题：

轮到我行动时，我应该做什么？

主要代码写在：

src/TeamAlphaWarrior.java

策略入口是：

public Action chooseAction(GameState state, UnitInfo self)

state 表示当前局面，self 表示正在行动的自己。你根据局面判断，然后返回一个行动，例如移动、攻击、防御或等待。

需要观察某个判断值时，可以在策略里加入追踪语句。追踪内容会显示在“单步策略调试”中，并且每一步都会自动刷新。

state.traceValue("self.getHealth()", self.getHealth());

独立完成

这个项目需要你独立完成。不要使用生成式工具、代码代写工具或他人生成的完整策略代码。

你可以阅读项目注释、示例代码和本指南，也可以和他人讨论思路；最终提交的策略代码必须由你自己写出，并且能逐行解释。无法解释的代码按未完成处理。修改比赛框架来绕过规则按无效提交处理。

双击启动

Windows 中在项目文件夹里双击：

启动仿真UI.bat

它会自动编译 src 文件夹里的 Java 代码，然后打开可视化仿真界面。代码有编译错误时，窗口会停在错误信息处；修好代码后再次双击这个文件。

macOS 中在项目文件夹里双击：

启动仿真UI.command

如果系统提示没有权限，打开“终端”，进入项目文件夹后执行一次：

chmod +x 启动仿真UI.command

之后再双击 启动仿真UI.command 即可。

在 VS Code 中运行

用 VS Code 打开整个项目文件夹 csa_warriors，不要只打开一个 .java 文件。

第一次运行前确认已经安装：

JDK 17 或更高版本
VS Code 的 Extension Pack for Java

运行图形界面：

  1. 按 Ctrl+Shift+B 编译全部代码。
  2. 点击左侧“运行和调试”。
  3. 选择 Visual Debugger。
  4. 点击绿色运行按钮。

运行控制台比赛：

  1. 点击左侧“运行和调试”。
  2. 选择 Console Match。
  3. 点击绿色运行按钮。

每次修改策略以后，都要重新编译，再从新比赛开始观察。

终端命令

图形界面：

javac --release 17 -encoding UTF-8 -d out src\*.java
java -cp out ArenaUiMain

控制台比赛：

javac --release 17 -encoding UTF-8 -d out src\*.java
java -cp out Main

第一行是编译命令，把 src 里的 Java 源码编译到 out 文件夹。第二行是运行命令，从 out 文件夹启动对应程序。

可视化调试界面

默认调试地图中，红队两名战士使用 TeamAlphaWarrior，蓝队、绿队、黄队使用 AllianceEncirclingWarrior。修改并重新编译 TeamAlphaWarrior.java 后，直接点 下一步 就能观察新策略。

  • 下一步：只让一个战士行动一次，方便观察 chooseAction 的结果。
  • 下一回合：让所有还活着的战士各行动一次。
  • 自动播放：连续播放比赛。
  • 重置：重新开始默认比赛，红队重新读取 TeamAlphaWarrior。
  • 点击地图上的战士：查看生命、攻击力、攻击范围、位置和状态。
  • 单步策略调试：查看当前战士、场上生命值、返回行动和策略追踪信息。
  • 动作动画：蓝色表示移动，红色表示攻击，蓝色光圈表示防御，金色光圈表示拾取道具。
  • 战斗日志：查看每一步移动、攻击、防御、治疗和死亡信息。
  • 评分报告：查看每队得分来源。
  • 队内 PK：给四个队伍的 A/B 两名战士分别选择策略，载入仿真或后台连测。
  • 批量连测：输入轮数 N，后台连续运行 N 局，直接查看胜负和得分汇总。
  • 项目文件：打开策略文件、示例代码和指南，修改代码后编译并重启界面。

修改策略的流程

  1. 在 项目文件 中打开 src/TeamAlphaWarrior.java。
  2. 修改 chooseAction 里面的策略区。
  3. 需要观察具体数值时，加入 state.traceValue(...)。
  4. 保存文件。
  5. 回到可视化界面。
  6. 点击 编译并重启界面。
  7. 新界面打开后，点击 下一步 测试新策略。

回合与无进展判负

比赛没有固定总回合上限。

如果连续 30 个完整回合没有任何状态变化，比赛结束，存活队伍触发无进展判负，不产生胜利者。

状态变化包括：

单位位置变化
单位生命变化
单位被击败
防御状态变化
攻击力或攻击范围变化
地图道具位置或类型变化

界面顶部会显示无状态变化倒计时。正常情况下显示剩余 30 回合；一旦进入无变化状态，会显示“已连续 X 回合无状态变化，剩余 Y 回合判负”。

调试时重点观察这些问题：

  1. 低血量时是否会治疗、撤退或防御。
  2. 敌人在攻击范围内时是否会攻击。
  3. 是否卡在墙边或原地等待。
  4. 是否攻击了正确目标。
  5. 是否会为了辅助道具改变路线。
  6. 是否出现无效移动、无效攻击或无进展扣分。

批量连测

进入 Visual Debugger 后，点击右侧的 批量连测 标签页。

操作流程：

  1. 在 连测轮数 N 中输入整数，例如 20。
  2. 点击 开始连测。
  3. 等待进度条完成。
  4. 查看每队胜场、胜率、平均分、最高分、最低分、总分。
  5. 查看总伤害、击败数、道具数、回血量、交战敌人数量和扣分情况。
  6. 点击 查看得分细节 打开得分窗口，选择队伍后查看该队的类别分数图、类别分数表和每局明细。
  7. 在得分窗口中选中某一局，点击 回放选中局，查看该局四个队伍的完整过程。

批量连测不会立即播放比赛过程，会在后台直接运行当前界面选择的队伍和策略。最近一次连测的对局回放会保存在内存中；下一次连测开始时会清空并覆盖旧缓存。单次最多连测 500 局。为了避免错误策略无限运行，后台单局超过 2000 回合仍未结束时，会记为“超过保护上限未结束”。

队内 PK

进入 Visual Debugger 后，点击右侧的 队内 PK 标签页。

操作流程：

  1. 在红队、蓝队、绿队、黄队中，为 A/B 两名战士分别选择策略类。
  2. A/B 可以选择同一个策略，也可以选择两个不同策略来分工配合。
  3. 点击 载入到仿真，左侧地图会使用这组配置重新开始。
  4. 点击 下一步、下一回合 或 自动播放 观察对战。
  5. 如果只想看统计结果，在 连测轮数 N 输入数字后点击 后台连测。
  6. 默认后台连测每局使用新的随机序列；勾选 固定随机种子 后，可以复现同一组随机测试条件。
  7. 勾选 轮换四个起点 后，会自动让四个队伍轮流从不同起点开始测试。
  8. 连测完成后点击 查看得分细节，选择队伍并逐局检查分数来自进攻、资源、恢复、存活还是扣分。
  9. 在明细表中选中某一局后点击 回放选中局，查看这一局的完整四队过程。

新建或修改策略类后，先到 项目文件 标签页点击 编译并重启界面，再回到 队内 PK 刷新策略列表。

4V4 联队对抗

进入 Visual Debugger 后，点击右侧的 4v4 联队 标签页。这个模式会创建两个真正的阵营：

  • 挑战方 1 和 挑战方 2 合并为挑战阵营，共 4 名战士。
  • 基准方 1 和 基准方 2 合并为基准阵营，共 4 名战士。
  • 同一阵营内的 4 名战士互为队友，不会互相攻击。
  • 策略中调用 state.getLivingTeammates(self) 时，可以看到同阵营其他 3 名存活队友。

默认配置下，挑战方使用 TeamAlphaWarrior，基准方使用 AllianceEncirclingWarrior。你需要在规则允许的公开接口内，设计能与队友配合的挑战策略，对抗这套合作型基准策略。

操作流程：

  1. 将挑战方 1 和挑战方 2 的 A/B 战士设置为自己的策略类。
  2. A/B 可以使用同一个策略，也可以使用两个不同策略实现分工。
  3. 点击 载入到仿真，左侧地图会变成当前 4V4 配置。
  4. 点击 下一步 观察每个战士本步的判断、追踪信息和行动结果。
  5. 输入连测轮数后点击 后台连测，查看挑战方与基准方的胜率、得分和细项数据。
  6. 点击 查看得分细节，选择阵营后检查每一局的分项分数和回放。

恢复默认 会把挑战方恢复为 TeamAlphaWarrior，把基准方恢复为 AllianceEncirclingWarrior。新策略文件复制到 src 后，需要先编译并重启界面，再刷新策略列表。

添加其他队伍策略

如果要加入其他队伍写好的策略：

  1. 在 队内 PK 中点击 打开策略文件夹，打开 src 文件夹。
  2. 把对方的策略 .java 文件复制到 src 文件夹。
  3. 确认每个队伍使用自己选择的唯一策略名，并让文件名、public class 名、构造方法名保持一致。
  4. 确认这个类继承 Warrior。
  5. 回到 项目文件，点击 编译并重启界面。
  6. 回到 队内 PK，点击 刷新策略列表。
  7. 在下拉框中选择新策略。

如果策略类编译失败，它不会出现在下拉框里。

策略文件命名规则

名称由队伍自定，但必须同时满足下面规则：

  1. 只能使用英文字母、数字和下划线。
  2. 第一个字符必须是英文字母。
  3. 不能有空格、中文、标点符号或减号。
  4. 不能和项目里已经存在的类重名。
  5. 同一个 src 文件夹中不能出现两个相同的 public class 名字。

Java 要求文件名、public class 名和构造方法名三处一致。下面格式中的 ChosenName 换成队伍自己的英文策略名：

ChosenName.java
public class ChosenName extends Warrior
public ChosenName() {
    super("界面显示名称");
}

例如：

public class StormGuard extends Warrior {
    public StormGuard() {
        super("Storm Guard");
    }

    @Override
    public Action chooseAction(GameState state, UnitInfo self) {
        return Action.stay();
    }
}

对应文件名必须是：

StormGuard.java

日常练习可以直接在 src/TeamAlphaWarrior.java 中修改策略区。需要把多个队伍放进同一个项目做 PK 时，每个队伍按上面的命名规则使用自己的策略名。

最小策略代码

public class TeamAlphaWarrior extends Warrior {

    public TeamAlphaWarrior() {
        super("Team Alpha");
    }

    @Override
    public Action chooseAction(GameState state, UnitInfo self) {
        UnitInfo enemy = state.findNearestEnemy(self);

        if (enemy == null) {
            return Action.stay();
        }

        if (self.distanceTo(enemy) <= self.getRange()) {
            return Action.attack(enemy.getId());
        }

        return state.moveToward(self, enemy.getPosition());
    }
}

常用方法

找最近敌人：

UnitInfo enemy = state.findNearestEnemy(self);

找血量最低的敌人：

UnitInfo weakest = state.findWeakestEnemy(self);

找范围内血量最低的敌人：

UnitInfo target = state.findLowestHealthEnemyInRange(self);

找最近治疗点：

Position healing = state.findNearestHealingPoint(self);

找最近道具：

Position powerUp = state.findNearestPowerUp(self);

读取当前所有道具的位置和类型：

ArrayList<PowerUp> powerUps = state.getPowerUps();

查询某个位置上的道具类型：

PowerUpType type = state.getPowerUpTypeAt(position);

找最近的指定类型道具：

Position attackGem = state.findNearestPowerUpOfType(self, PowerUpType.ATTACK);

找最近的强力道具：

Position strong = state.findNearestStrongPowerUp(self);

判断某个位置是不是强力道具：

boolean strong = state.isStrongPowerUpAt(position);

道具类型：

类型含义
PowerUpType.HEALTH恢复生命
PowerUpType.ATTACK增加攻击力
PowerUpType.RANGE增加攻击范围
PowerUpType.MEGA_HEALTH大量恢复生命，属于强力道具
PowerUpType.POWER_CORE大幅增加攻击力，属于强力道具
PowerUpType.BATTLE_CORE恢复生命并增加攻击力和攻击范围，属于强力道具

向某个位置移动：

return state.moveToward(self, targetPosition);

远离某个位置：

return state.moveAwayFrom(self, dangerPosition);

攻击目标：

return Action.attack(enemy.getId());

防御：

return Action.defend();

等待：

return Action.stay();

显示一行调试说明：

state.trace("准备判断是否需要撤退");

显示某个表达式的具体值：

state.traceValue("self.getHealth()", self.getHealth());

显示某个战士的生命、攻击、范围和位置：

state.traceUnit("enemy", enemy);
