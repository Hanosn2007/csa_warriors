Java Warrior Arena 评分参数表

评分系统的主要参数集中在：

src/ScoreConfig.java

修改参数后，重新编译并运行项目即可生效。

当前默认参数

参数默认值含义
damagePoint1每造成 1 点伤害获得的分数
defeatBonus25击败一个敌人获得的额外分数
normalPowerUpBonus8拾取普通道具的分数
strongPowerUpBonus15拾取强力道具的分数
healingChunkSize5每多少点有效回血换算一次回血分
healingChunkPoint1每个回血块获得的分数
healingScoreCapPerUnit25每个战士单局最多获得的回血分
secondConsecutiveHealingPercent50同一治疗点连续第 2 次回血的分数比例
thirdConsecutiveHealingPercent0同一治疗点连续第 3 次及以后回血的分数比例
survivalPointPerRound1每存活到一回合结束获得的分数
survivalScoreCapPerUnit40每个战士单局最多获得的存活分
finalAliveBonus20比赛结束时每个存活战士的奖励
winnerBonus50胜利队伍额外奖励

noProgressPenalty5连续无进展行动触发的扣分
noProgressTurnsBeforePenalty3连续多少次无进展后扣分

防刷分设计

回血不会成为主要得分方式：

回血分有上限。
连续站在同一个治疗点回血会递减。
第 3 次及以后连续回血不再给回血分。

存活也不会无限刷：

每个战士的存活分有上限。
比赛结束存活有奖励，但不会压过伤害、击败和目标争夺。

无效行动会被扣分：

无效移动、无效攻击会扣分。
连续不移动、不得分、无实际进展，也会扣分。

调参方向

想让进攻更重要：

提高 damagePoint 或 defeatBonus
降低 survivalPointPerRound

想让资源争夺更重要：

提高 normalPowerUpBonus 和 strongPowerUpBonus

治疗点分数过高时：

降低 healingScoreCapPerUnit
降低 secondConsecutiveHealingPercent
保持 thirdConsecutiveHealingPercent 为 0

无效动作影响太小时：

提高 invalidActionPenalty
提高 noProgressPenalty
